# TidaLuna Plugins

A collection of [TidaLuna](https://github.com/Inrixia/TidaLuna) plugins made by me

## Plugins

### CoverFetcher
A plugin that adds cover art options to the context menu for songs and albums.

#### Features

- Download high-resolution cover art (up to 1280x1280) directly to your computer
- Copy the cover art URL to clipboard

Both options are available when right-clicking on:
- Individual tracks
- Albums

The plugin automatically selects the highest resolution available for each cover.

### UpNext
A plugin that shows the song which will be played next.

#### Features

- Display the next song
- Toggle displaying the artist of the next song
- Toggle displaying the cover art of the next song

### RightClickContextMenu
A plugin that adds the ability to open the context menu for tracks using right click in additional places.

#### Features

- Open track context menu with right click in the player
- Open track context menu with right click in albums/EPs when using the New media table feature flag
